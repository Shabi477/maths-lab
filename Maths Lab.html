    The curriculum

    Nine units follow the Maths Lab teaching order. Classroom provides the Classroom lessons; Catch-up targets the current unit or earlier skills a pupil needs. Choose a unit to see its lessons.

    How the programme works

    Every pupil learns in a class, and the class always moves on; some also have extra support. Aim: caught up by Year 8.

    Classroom keeps the class on the current unit; Catch-up organises extra teaching for identified gaps. The tier determines the support offered. Assessment evidence and the teacher's judgement determine which lessons each pupil needs.

    Who does what

    Head of department

    • Sorts pupils, sets classes
    • Reviews the groups each term
    • Decides at the end of the year

    Teacher

    • Teaches the class
    • Runs the Tier 2 extra lesson; chooses its gaps each week
    • Sets the Tier 3 lessons; reads the TA's notes

    TA or peer mentor

    • Teaches the Tier 3 small groups
    • Records each session's exit ticket in Catch-up
    • Flags a pupil who is stuck

    Using the apps

    1. 1. Set up provision

      In Catch-up's Plan, use Add pupils or Manage pupils and groups, then select pupils and their tier. Use Check → Tests for the Tier 2 readiness paper, and First assessment for Tier 3. Keep support groups for at least a term.

    2. 2. Plan and teach

      Tier 2: choose the Classroom lesson, tick one or two linked support lessons, then Set for the group. Tier 3: record each pupil's assessment gaps, review the proposed sequence, then Set plan. The TA or peer mentor opens Teach and records the exit ticket and help needed.

    3. 3. Review the support

      Use Classroom's Weekly sheet to note missed exit tickets. Three misses prompt closer monitoring. Review groups termly, mainly using unit tests; classes stay fixed for the year. Use section B across the year for the agreed Year 8 decision.

    Catch-up keeps pupil records in the browser you use. In Records, use Save a backup to keep a copy. Open a backup replaces the records on screen with that copy.

    Threshold concepts

    Threshold concepts are key mathematical ideas that many later lessons build on, such as place value, equal groups and inverse relationships. A gap here can affect several topics. Address the gap while the pupil continues with the class unit.

    1. 1. Find the idea

      Choose the current unit below, then open a concept. Read its explanation and note the lesson titles and codes that teach it.

    2. 2. Check the gap

      Use assessment responses, Get ready and class work to check understanding. Consider the pupil's explanation and any help needed, as well as their answer.

    3. 3. Teach and revisit

      Use Catch-up → Plan to select the pupil and set suitable lessons. Teach with the pictures and Show it; record the exit ticket, then revisit the idea in a later or mid-point check.
